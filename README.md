# 📍 Buscador de CEP

Aplicação web que consome a API pública ViaCEP para buscar informações de endereço a partir de um CEP.

## 🚀 Funcionalidades

- Busca de endereço por CEP
- Consumo de API externa
- Uso de async/await
- Tratamento de erro
- Manipulação de JSON

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript
- Fetch API

## 🎯 Objetivo

Demonstrar integração com API externa e manipulação de requisições HTTP utilizando JavaScript puro.
